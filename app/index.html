설치 파일 내려받기

APK 다운로드 약 1.3MB
  1. 버튼을 눌러 파일을 받습니다
  2. 받은 파일을 눌러 설치를 시작합니다
  3. “알 수 없는 앱 설치” 안내가 나오면 설정 → 이 출처 허용
  4. Play 프로텍트 경고에서 무시하고 설치
보안 경고는 정상입니다. 플레이 스토어에 등록되지 않은 앱은 누가 만들었든 이 경고가 나옵니다.

홈 화면에 추가

아이폰은 설치 파일이 없습니다. 아래 주소를 Safari로 열어 홈 화면에 추가하세요.

https://ddacbae.github.io/icunursehub/
  1. Safari로 위 주소를 엽니다
  2. 아래 가운데 공유 버튼(⬆️)을 누릅니다
  3. 목록을 내려 홈 화면에 추가를 누릅니다
  4. 오른쪽 위 추가를 누르면 끝입니다
반드시 Safari여야 합니다. 카카오톡이나 크롬으로 열면 “홈 화면에 추가”가 나오지 않습니다.
설치 후 앱은 자동으로 최신 상태를 유지합니다.
