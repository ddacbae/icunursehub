# ICU Nurse Hub – Apps Script

`Code.gs` 는 구글 스프레드시트에 붙여 넣는 코드입니다. 이 저장소의 웹앱(`index.html`, `app.js`)은
이 파일을 직접 불러오지 않고, 보관·이력 관리용으로만 두었습니다.

## 적용 순서

1. 스프레드시트 → **확장 프로그램 → Apps Script** 열기
2. 기존 `Code.gs` 내용을 전부 지우고 이 파일 내용을 붙여넣기 → 저장
3. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**
   - ⚠️ 새로 배포하지 말고 **기존 배포를 수정**해야 앱의 전송 URL이 그대로 유지됩니다.
4. 스프레드시트를 새로고침하면 상단에 **📋 ICU 보고서** 메뉴가 생깁니다.
5. 메뉴 → **기존 ✓/— 데이터를 0/1 로 변환** 을 한 번 실행 (백업 시트가 자동 생성됨)
6. 메뉴 → **매월 자동 생성 켜기** 로 트리거 등록 (권한 승인 필요)

## 하는 일

| 기능 | 설명 |
|---|---|
| 0/1 저장 | 앱이 보내는 `✓` / `—` 를 받는 즉시 `1` / `0` 으로 변환. 해당없음(`N/A`)은 빈칸 |
| QM 열 교정 | 앱이 인계메모를 10번째로 보내는 것을 맨 뒤로 옮겨 헤더와 맞춤 |
| QM 과거 데이터 교정 | 예전에 밀려 저장된 근무자/책임간호사/침상번호 열을 바로잡음 (여러 번 실행해도 안전) |
| 월간 보고서 | `월간보고서_YYYY-MM` 시트 생성 + 드라이브 `ICU 월간보고서` 폴더에 PDF 저장 |
| 자동 실행 | 매월 1일 새벽 2시에 전월 보고서 자동 생성 |

## 준수율 계산 방식

```
준수율 = 1 의 개수 ÷ (1 또는 0 인 칸의 수)
```

빈칸(해당없음)은 분모에서 제외됩니다. 예를 들어 나이트 전용 항목인
`기록모니터링-비대면인계` 는 데이/이브닝 근무 행에서 빈칸이 되어 준수율을 깎지 않습니다.

## 3단계 체크 (수행 / 미수행 / 해당없음)

퀵라운딩 · 책임간호사 라운딩 · QM 업무체크리스트는 항목마다 세 가지로 입력합니다.
GAS 는 이미 세 가지를 모두 처리하므로 **이 변경으로 시트나 코드를 고칠 필요는 없습니다.**

| 앱 입력 | 전송값 | 시트 저장 | 준수율 |
|---|---|---|---|
| 수행 | `✓` | `1` | 분자·분모 |
| 미수행 | `—` | `0` | 분모만 |
| 해당없음 | `N/A` | 빈칸 | 제외 |

앱이 보내는 `완료항목` / `전체항목` 도 같은 기준입니다 —
`전체항목 = 전체 − 해당없음` 이라 시트가 계산하는 준수율과 값이 일치합니다.

**빠짐없이 입력해야 저장됩니다.** 세 항목 중 하나를 고르지 않은 칸이 하나라도 있으면
저장이 막히고 해당 줄이 노란색으로 표시됩니다. 근무자 이름도 필수입니다.
(글로 적는 칸 – 인계메모 – 은 비워 두어도 됩니다)

점검 항목으로 세지 **않는** 열: `Vent여부`, `도뇨관보유`, `무른변환자`
(점검 결과가 아니라 환자 상태 표시이므로 0/1 로는 저장하되 통계에서는 제외)

## 주의

- `QM_FIX_ORDER = true` 는 앱(`app.js`)이 지금처럼 인계메모를 10번째로 보낸다는 전제입니다.
  나중에 `app.js:1994` 의 전송 순서를 직접 고친다면 이 값을 `false` 로 바꿔야 합니다.
  양쪽 다 고치면 열이 다시 밀립니다.
- 기존 데이터 변환은 QM 열 교정 때문에 **한 번만** 실행되어야 하며,
  실행 후 스크립트 속성 `QM_REORDER_DONE` 에 잠금이 걸려 재실행해도 중복 교정되지 않습니다.

## 유치도뇨관 – 시간대별 저장

한 근무(D/E/N) 안에서 확인 시간(예: 09:30 / 11:30 / 14:30)을 골라 그때그때 저장합니다.
GAS 가 `시행일 + 근무 + 침상번호` 가 같은 행을 찾아 덮어쓰므로(`UPSERT_KEYS`),
같은 근무에서 세 번을 저장해도 **침상당 한 줄**로 유지됩니다.

```
09:30 저장 → 3번 | 1 | 0 | 0
11:30 저장 → 3번 | 1 | 1 | 0   ← 같은 줄 갱신
14:30 저장 → 3번 | 1 | 1 | 1   ← 같은 줄 갱신
```

`확인자` 열은 앱에서 입력란을 없앴으므로 앞으로 빈칸입니다.
(열 자체는 시트 열 개수를 유지하기 위해 남겨 둡니다)
